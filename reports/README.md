# 📈 Reports

This folder contains the reports, graphs, charts, and other outputs generated during the **Predictive Analytics for Road Accident Prevention** project.

## 📁 Folder Structure

```text
reports/
│
├── README.md
│
├── figures/
│   ├── accident_severity_distribution.png
│   ├── weather_vs_severity.png
│   └── confusion_matrix.png
│
└── final_report.pdf
```

## 📊 Figures

The `figures/` folder contains visualizations generated during Exploratory Data Analysis and model evaluation.

### `accident_severity_distribution.png`

Shows the distribution of different accident severity classes in the dataset.

### `weather_vs_severity.png`

Shows the relationship between weather conditions and accident severity.

### `confusion_matrix.png`

Shows the performance of the machine learning classification model by comparing actual and predicted accident severity classes.

## 📄 Final Report

The `final_report.pdf` contains the complete project report.

It includes:

* Project introduction
* Problem statement
* Objectives
* Dataset description
* Data preprocessing
* Exploratory Data Analysis
* Feature engineering
* Machine learning methodology
* Model evaluation
* Prediction results
* Streamlit application
* Conclusion

## 📌 Purpose

The reports help document the analysis and results of the project in an easy-to-understand visual and written format.
